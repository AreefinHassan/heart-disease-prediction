# Data

The SAheart data set is **not** committed to this repository — it is downloaded directly by the analysis script from its public source:

- **URL:** https://web.stanford.edu/~hastie/ElemStatLearn//datasets/SAheart.data
- **Source:** Coronary Risk-Factor Study, as distributed with *The Elements of Statistical Learning* (Hastie, Tibshirani & Friedman)

The file is a comma-separated table with 462 rows (males aged 15–64, Western Cape, South Africa) and 10 columns: the response `chd` plus 9 predictors (`sbp`, `tobacco`, `ldl`, `adiposity`, `famhist`, `typea`, `obesity`, `alcohol`, `age`). Row names are the observation numbers.
